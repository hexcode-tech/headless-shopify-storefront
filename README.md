# NovaCart — Headless Shopify Storefront (Starter)

NovaCart is a modern, minimal headless Shopify storefront starter using Next.js + TypeScript + Tailwind CSS. It's scaffolded for hexcode-tech to help you launch a storefront with guest checkout, multi-currency support, and internationalization.

About (catchy):
NovaCart — Discover unique finds from around the world. Shop independent boutiques with guest checkout, localized pricing, and reliable shipping. Curated products, beautiful product pages, and a checkout experience your customers will love.

Getting started
1. Install dependencies
   npm install

2. Create a Shopify dev store
   - Sign up for a Shopify Partner account: https://www.shopify.com/partners
   - Create a development store from the Partner dashboard
   - In the Shopify admin, create a Storefront API Access token (Apps > Develop apps > Create app > Storefront API access)

3. Add environment variables
   Copy `.env.example` to `.env.local` and add your store domain and token.

4. Run locally
   npm run dev
